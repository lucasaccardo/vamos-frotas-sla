Excel (.xlsx)

Formato ideal para análise de dados. Inclui formatação de colunas, datas formatadas (dd/mm/YYYY) e valores com 2 decimais. Colunas auto-ajustadas.

CSV

Formato universal compatível com qualquer ferramenta. Recomendado para volumes muito grandes ou importação em outros sistemas.

Observações Importantes
  • Os relatórios incluem todas as colunas principais: dados do ativo, financeiro, status, SLA e observações.
  • Os filtros são aplicados no servidor antes da geração do arquivo.
  • Para volumes muito grandes (>10.000 registros), considere usar CSV para melhor performance.
  • Arquivos gerados incluem timestamp no nome para facilitar organização.
  • Campo "SLA" mostra o prazo máximo configurado para o setor atual.
  • Aprovador O.S. é exibido quando o processo está aguardando aprovação.
